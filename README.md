
# Predictive Healthcare Risk Classification

## Overview
This project predicts patient healthcare risk levels using machine learning classification algorithms.

## Models Used
- Logistic Regression
- KNN
- Random Forest
- Gradient Boosting
- Voting Classifier

## Results

| Model | Recall |
|--------|--------|
| Logistic Regression | 82.8% |
| KNN | 88.3% |
| Random Forest | 95.8% |
| Gradient Boosting | 94.9% |
| Voting Classifier | 93.07% |

## Best Model
Random Forest achieved the highest recall (95.8%) and accuracy (93.7%), making it the final selected model.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
